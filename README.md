# Vitals - CLI

[![CI](https://github.com/zamir-studio/vitals-cli/actions/workflows/ci.yml/badge.svg)](https://github.com/zamir-studio/vitals-cli/actions/workflows/ci.yml)
[![Rust](https://img.shields.io/badge/Rust-1.98.1-blue?logo=rust)](https://rust-lang.org)

A local-first command-line tool for tracking personal health vitals (blood pressure, physical activity, and nutrition), 
written with Rust 🦀. 

All data stays on your machine; there is no cloud sync and no external API calls.

> **Disclaimer:** This tool is for personal tracking and informational
> purposes only. It does not diagnose, treat, or provide medical advice.
> Consult a qualified healthcare professional for medical decisions.

## Features

This project is in early development. No features are implemented yet.

## Requirements

- Rust 1.98.1 (pinned via `rust-toolchain.toml`)

## Building

```bash
cargo build
```

## Testing

```bash
cargo test
```
